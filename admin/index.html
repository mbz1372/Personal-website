مشاهده سایت

مدیریت نوشته‌ها

سه کارت بخش Thinking سایت از این داده خوانده می‌شود. بعد از ویرایش، خروجی JSON را کپی کن و در فایل script.js مقدار defaultArticles را جایگزین کن.

اطلاعات پروفایل

اطلاعات اصلی از رزومه وارد شده است. برای تغییر شماره، ایمیل، لینکدین یا عنوان حرفه‌ای، فایل index.html را بروزرسانی کن.

راهنمای انتشار روی Vercel

این نسخه Static است؛ یعنی نیاز به npm install، build سنگین یا Output Directory خاص ندارد. اگر Vercel پرسید:

Framework Preset: Other Build Command: خالی بگذار Output Directory: خالی یا . Install Command: خالی

اگر قبلاً روی پروژه Build Command تنظیم شده، حذفش کن تا Vercel فایل index.html را مستقیم سرو کند.
