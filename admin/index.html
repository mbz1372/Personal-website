مشاهده سایت

Static · Vercel Safe · No Database

پنل سبک برای مدیریت محتوا

این سایت عمداً استاتیک طراحی شده تا مثل نسخه پروداکشن فعلی روی Vercel بدون خطای build و بدون وابستگی اجرا شود. برای تغییر محتوا، داده‌های رزومه در فایل script.js قرار دارند و ظاهر در styles.css کنترل می‌شود.

محتوای دو زبانه

کل متن‌های فارسی و انگلیسی داخل آبجکت‌های content و data در script.js هستند.

ساختار صفحه

Hero، profile card، timeline، پروژه‌ها، کیس‌استادی و تماس داخل index.html تعریف شده‌اند.

طراحی و UX

پوسته رزومه، responsive، dark mode، print style و spacing داخل styles.css قرار دارد.

Deployment

برای این نسخه build command لازم نیست. اگر Vercel تنظیمات قبلی داشت، بهترین حالت برای static deploy این است:

Framework Preset: Other
Build Command: empty
Install Command: empty
Output Directory: .
